Automação • Backend • APIs • Cloud
oferta-bot
Plataforma autoral para automação de ofertas, tracking e publicação. Desenvolvida em Node.js + TypeScript com Express e Prisma, possui API REST, banco de dados, worker em background, geração de links rastreáveis, analytics, templates e integrações com APIs externas. Implantada em VPS Ubuntu com PM2, Caddy e HTTPS.
  • Dados: modelagem relacional com Prisma/SQLite para ofertas, campanhas, canais, templates, cliques, conversões e publicações.
  • Automação: worker com scheduler, ranking de ofertas, feature flags, idempotência e retries controlados.
  • Integrações: Telegram Bot API implementada e testada; arquitetura multicanal com dry-run por plataforma e diagnóstico de credenciais.
  • Segurança: sessão administrativa com senha em hash, cookies HttpOnly/SameSite, rate limiting e secrets fora do Git.
  • Qualidade: testes automatizados, TypeScript strict/typecheck e pipeline com GitHub Actions.
TypeScript Node.js Express Prisma SQLite REST API Telegram API Linux Oracle Cloud PM2 Caddy GitHub Actions
